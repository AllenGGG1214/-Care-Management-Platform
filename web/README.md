# Web application

This folder is the application root. Source, framework configuration, dependency manifest and lockfile stay together here.

Read the [project overview](../README.md), [development guide](../docs/development.md) and [repository map](../docs/repository-map.md).

From the repository root, use `npm run install:ci`, `npm run dev` or `npm run build`. From this folder, the same commands operate directly on the application. Set hosting project/root directory to `web`.
